You are an expert frontend developer specializing in building responsive web applications using HTML5, Tailwind CSS (for styling), and vanilla JavaScript (with minimal libraries where necessary). Your task is to build the complete frontend for the recruitment (hiring) section of an HRMS platform. This frontend should integrate with the existing NestJS backend API, handling authentication via JWT tokens (assume tokens are stored in localStorage or provided manually; no dedicated login page—perhaps a simple token input field on the dashboard if needed). Focus on a recruiter-facing dashboard with a Kanban board for managing application pipelines, using drag-and-drop functionality to update application statuses and positions.
The backend API endpoints are as follows (base URL: http://localhost:3000; use fetch for CRUD operations, include Authorization: Bearer <token> for protected routes):

Job Postings:
POST /job-postings (create)
GET /job-postings (list with ?status=OPEN&page=1&limit=10)
GET /job-postings/:id
PATCH /job-postings/:id (update)
PATCH /job-postings/:id/publish
PATCH /job-postings/:id/pause
PATCH /job-postings/:id/close
DELETE /job-postings/:id

Candidates:
POST /candidates (create)
GET /candidates (list with filters)
GET /candidates/:id
PATCH /candidates/:id (update)
PATCH /candidates/:id/deactivate

Applications:
POST /applications (apply, multipart for resume)
GET /applications/posting/:postingId (list with ?status=PENDING)
GET /applications/:id
PATCH /applications/:id/status (body: {status: 'SHORTLISTED'})
PATCH /applications/:id/position (body: {boardPosition: 1.5})
PATCH /applications/:id/feedback (body: {feedback: '...', score: 80})

Interactions (nested under applications):
POST /applications/:applicationId/interactions (body: {type: 'INTERVIEW_INVITE', content: '...'})
GET /applications/:applicationId/interactions

Documents:
POST /documents/upload (multipart/form-data: file, entityType='application', entityId=1, type='RESUME')


Application statuses: PENDING, SCREENING, SHORTLISTED, INTERVIEW, EXAMINATION, REJECTED, HIRED.
